# Free n8n templates

These workflows are free to download. Each one calls a Data Scrapers actor on Apify with your own API token. Actor runs and the services you connect can cost money.

## Turo

- [Save a Turo car search to an n8n data table](templates/turo-cars-to-data-table/README.md)
- [Monitor Turo prices for the same trip](templates/turo-trip-price-monitor/README.md)
- [Save Turo calendar days for a trip search](templates/turo-availability-calendar/README.md)
- [How to compare a Turo trip price over time](articles/monitor-turo-trip-prices.md)

The actor is [Turo Car Scraper](https://apify.com/datascrapers/turo-car-scraper).
